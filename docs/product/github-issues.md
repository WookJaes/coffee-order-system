# 구현 순서

한 번에 하나의 항목만 구현한다. 각 항목은 구현 전 `specs/` 또는 해당 문서의 완료 기준을 확인하고, 완료 후 검증 로그를 남긴다.

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 프로젝트 기반 구성 | 문서, 패키지, 로컬 실행 기준이 정리됨 |
| 2 | Flyway 스키마와 메뉴 seed | 테이블, 제약조건, 초기 메뉴가 재현됨 |
| 3 | 메뉴 목록 조회 | 메뉴 ID, 이름, 가격 계약과 테스트가 통과함 |
| 4 | 포인트 충전 | 금액 검증, 잔액 갱신, 이력 저장이 통과함 |
| 5 | 주문 및 결제 | 멱등성, 비관적 락, 트랜잭션, 잔액 차감이 통과함 |
| 6 | Outbox와 Kafka 발행 | 주문 완료 이벤트가 유실 없이 발행 대상에 저장됨 |
| 7 | Kafka Consumer와 Redis 랭킹 | 중복 이벤트 안전성, DLT, ZSET 누적이 통과함 |
| 8 | 인기 메뉴 Top 3 | 최근 7일, 동점 정렬, Redis 장애 복구 기준이 확인됨 |
| 9 | HTTP 및 k6 검증 | 정상/실패 API와 Load/Stress/Spike 결과가 기록됨 |
