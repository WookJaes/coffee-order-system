# 요구사항

## 필수 기능

1. 메뉴 ID, 이름, 가격을 조회한다.
2. 사용자 식별값과 충전 금액으로 포인트를 충전한다. 1원은 1P다.
3. 사용자 식별값과 메뉴 ID로 주문하고 포인트로 결제한다.
4. 주문 완료 정보를 데이터 수집 플랫폼에 실시간 전송한다.
5. 최근 7일 주문 수 기준 인기 메뉴 Top 3를 조회한다.

## 비기능 요구사항

- 다수 애플리케이션 인스턴스가 공통 MySQL, Redis, Kafka를 사용해도 정합성이 유지돼야 한다.
- 포인트 차감은 동시 요청에서도 잔액이 음수가 되지 않아야 한다.
- 주문, 포인트 사용 이력, Outbox 이벤트 저장은 하나의 트랜잭션으로 처리한다.
- Kafka Consumer는 중복 메시지를 안전하게 처리하고 반복 실패 메시지는 DLT로 이동한다.
- 기능과 제약사항은 테스트로 검증한다.

## 범위 제외

- 로그인, OAuth, JWT 인증/인가
- 메뉴 관리용 관리자 API
- 환불 및 주문 취소 API
- 실제 MySQL Primary-Replica, Redis Sentinel/Cluster 운영 구성

운영 고가용성 구조는 README 설계 설명으로 남기며, 로컬 구현은 단일 인프라 인스턴스를 기준으로 한다.
